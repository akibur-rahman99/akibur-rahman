Background

I'm Akibur Rahman, a CSE student from Dhaka. Since childhood I've been curious about how technology and science work, and I like turning that curiosity into projects that actually run.

At AIUB I'm majoring in cyber security. The goal is simple: learn how systems get attacked, then use that knowledge to help defend them.

Focus
  • Security toolkit: Linux, networking and Python
  • Software I build: Android, graphics and management systems in Kotlin, C++, Java and C#
  • Code in the open: github.com/akibur-rahman99
Latest build

MedLink is an Android health app with five roles (Admin, Doctor, Nurse, Patient and Guardian), built with Kotlin, Jetpack Compose, Cloud Firestore and Firebase Authentication. It books appointment and lab slots, tracks medicine adherence, and reads prescriptions with Gemini-powered OCR.

Before it came Journey by Bus, a four-scene OpenGL animation, plus hospital and university management systems.
